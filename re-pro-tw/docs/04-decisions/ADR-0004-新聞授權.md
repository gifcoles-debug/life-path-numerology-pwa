# ADR-0004｜新聞只存標題與原文連結；非商業授權的來源，收費前需要 Owner 決定

- **狀態**：待 Owner 決定（2026-11-15）
- **背景**：
  - 中央社 RSS 限個人或非營利使用（VERIFIED）。
  - Google 新聞 RSS 的條款以個人、非商業用途為主（INFERRED）。
  - 經濟日報 RSS 的條款沒查到（UNKNOWN）。
- **暫定做法**：
  - 中央社預設關閉，其餘開啟，只存標題與連結，不轉載內文。
  - 正式收費前三選一：
    1. 取得授權
    2. 改用政府新聞稿與已授權來源
    3. 新聞功能只開給免費的基本會員
