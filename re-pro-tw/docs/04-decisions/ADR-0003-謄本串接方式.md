# ADR-0003｜謄本採用「供應商轉接層」，第二階段先串接共享協作平台

- **狀態**：採用（2026-11-14）
- **背景**：查證結果（docs/02-research/TRANSCRIPTS.md）
  - 中華電信、關貿都沒有公開 API（UNKNOWN：需要直接洽詢）。
  - 內政部共享協作平台每筆約 1 元，但不提供私人所有權人的個資（VERIFIED）。
- **決定**：
  - 前端與點數扣款流程固定，後面的供應商可以替換：manual → cop／upload → landTelecom。
  - 對外不承諾「站內調閱具法律效力的謄本」。
- **影響**：第二階段先開放共享協作平台與上傳自購謄本，再與電傳業者洽談。
