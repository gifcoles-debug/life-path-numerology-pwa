# ADR-0001｜採用 Node.js 單體架構＋內建 SQLite

- **狀態**：採用（2026-11-14）
- **背景**：要盡快做出會員可用的版本，維運人力只有 Owner 加 AI，沒有專職工程師。
- **決定**：
  - 用 Node.js 22 與 Express 做單一服務，資料庫用內建的 `node:sqlite`，前端是不使用框架的單頁應用。
  - 依賴只有 4 個套件：express、fast-xml-parser、adm-zip、chart.js。
- **理由**：
  - 不需要另外架資料庫，一台主機就能跑。
  - 備份只要複製一個資料夾。
  - 依賴少，壞掉的機會也少。
- **影響**：
  - 同時寫入的量有上限。估計 2,000 位會員以內足夠（INFERRED）。
  - 超過時改用 PostgreSQL。資料表沒有用到 SQLite 專屬功能，可以搬移。
- **重新檢討的條件**：同時在線超過 200 人，或需要多台主機。
