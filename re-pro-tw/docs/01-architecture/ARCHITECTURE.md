# 架構與框架設計

## 核心原則：先串接、後自建

資料量很大，所以不自己蒐集全部資料，而是用一個**框架**把每種資料「從哪裡來、怎麼取得、多準、多久更新、要不要錢」標清楚，再依價值高低逐步內建。

```
             ┌──────────── 資料來源層 ────────────┐
外部連結(link) │ 開放資料(open-data) │ RSS │ API │ 付費(paid)
             └──────┬───────────────┬────────────┘
                    │ 每日排程（src/scheduler.js）
     ┌──────────────┼───────────────┬──────────────────┐
  連結確認        新聞擷取        實價登錄匯入       （第二階段）謄本／建照／利率
 linkcheck.js     news.js          lvr.js            transcripts/ 轉接層
     └──────────────┴───────┬───────┴──────────────────┘
                            ▼
                 SQLite（storage/repro.db）
     link_status · news · trades · trade_stats · users · points_ledger …
                            ▼
                 會員 API（src/routes.js，依方案權限）
                            ▼
      首頁總覽 · 房價走勢 · 每日資訊 · 謄本中心 · 資源整合庫 · 試算
```

## 「框架」＝ `data/catalog.json`

每個模組就是一個主題頁，包含以下欄位：

- `summary`：這一類資料是做什麼用的
- `analysis`：**這類資料可以怎麼分析**（例如「建照核發量 → 1～3 年後的新屋供給」）
- `status`：`live`（站內已有功能）、`links`（連結整合）、`planned`（規劃中）
- `groups[].items[]`：每個來源都有下列標註

| 欄位 | 意義 | 可用值 |
|---|---|---|
| `trust` | 來源可信度 | official 官方一手、industry 業者／公會、research 研究機構、media 媒體報導 |
| `access` | 取得方式，決定能不能自動化 | link、open-data、rss、api、paid |
| `update` | 更新頻率 | 文字，例如「每月 1、11、21 日」 |
| `cost` | 費用 | 免費、付費、部分付費 |

**哪些適合放在一起、一起分析：**

| 分析主題 | 結合的資料 |
|---|---|
| 房價走勢 | 實價登錄（成交） ＋ 住宅價格指數／信義／國泰／政大永慶指數（指數） ＋ 591 等刊登平台（開價） |
| 供給壓力 | 建照、使照核發量 ＋ 預售屋實價登錄 ＋ 營造工程物價指數 |
| 購屋能力 | 央行房貸利率、信用管制 ＋ 景氣燈號 ＋ 單價走勢 |
| 個案評估 | 謄本（權利、抵押） ＋ 公告現值 ＋ 使用分區 ＋ 災害潛勢 ＋ 周邊成交 |
| 稅負試算 | 公告現值／地價 ＋ 持有年限 ＋ 房地合一、土增稅、遺贈稅規定 |

## 資料準確度原則

1. **標來源**：每張圖、每則新聞、每個連結都顯示來源與可信度等級。
2. **用中位數**：房價用單價中位數，同時顯示 25%～75% 區間，不用平均數。
3. **排除特殊交易**：備註含親友、員工、特殊關係、瑕疵、凶宅、法拍、毛胚、持分、含增建等的交易，以及純土地、純車位交易，都不列入行情；原始資料仍保留，明細表以淡色顯示。
4. **登錄時差**：最近 1～2 個月的資料還沒登錄完整。首頁快照取件數 ≥ 30 的最新月份，圖表上也有註明。
5. **每日連結確認**：
   - 失效連結（404、5xx、逾時）標紅。
   - 網站有回應但阻擋機器人（403、429）的標黃，請人工確認。
6. **示範資料**：只用來預覽畫面，畫面上有浮水印與警示；匯入真實資料時自動清除。

## 會員與權限

| 方案 | 可用功能 |
|---|---|
| 基本 | 總覽、每日資訊、資源整合庫、試算工具、謄本中心 |
| 專業 | 基本會員全部功能 ＋ 房價走勢分析 |
| 企業 | 專業會員全部功能 ＋ 團隊（預留） |

- 方案到期後自動以基本會員權限使用，資料不刪除。
- 帳號被停用時，所有登入狀態立即失效。

**安全措施：**

- 密碼以 scrypt 加鹽雜湊儲存。
- Session token 在資料庫只存雜湊值；Cookie 設為 HttpOnly 與 SameSite=Lax，正式環境加上 Secure。
- 同一 IP 加同一帳號，15 分鐘內最多嘗試登入 10 次。
- 會改資料的請求必須來自本站（檢查 Origin）。
- 設有 CSP 等安全標頭。

## 發展藍圖

**第一階段（已完成）：整合框架。** 包括會員制、資源整合庫加連結確認、每日新聞、實價登錄分析、謄本中心（說明與需求單）、試算工具。

**第二階段：付費與資料內建**
- 金流（綠界、藍新等）：方案訂閱、點數儲值、電子發票
- 謄本：先串接內政部共享協作平台 API，並開放上傳自購謄本、自動查驗與歸檔（見 TRANSCRIPTS.md）
- 用 `openapi.land.moi.gov.tw` 的免費 API 查公告現值與公告地價
- 建照、使照開放資料，以及營造工程物價指數、央行房貸利率、景氣燈號的圖表
- 推薦名單（代書、室內設計、估價師）與會員評價
- 法規與判決的關鍵字訂閱，每天寄 Email 摘要

**第三階段：自建台灣不動產地圖**
- 用國土測繪中心的圖資當底圖，疊上成交點、使用分區、捷運站、災害潛勢
- 輸入物件位置，一鍵產出包含周邊行情、風險、分區的分析報告
- 開放 API 給企業會員串接
