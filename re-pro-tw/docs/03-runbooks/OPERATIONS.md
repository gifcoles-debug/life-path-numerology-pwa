# 日常維運（誰、何時、做什麼）

| 頻率 | 工作 | 誰（人／AI 員工） | 怎麼做 |
|---|---|---|---|
| 每天（自動） | 新聞（每 3 小時）、連結確認、實價登錄（06:00 後） | 排程 | `src/scheduler.js` |
| 每天 | 看首頁「資料更新狀態」三個燈號 | Owner（1 分鐘） | 有紅燈就交給除錯工程師 |
| 每天 | 審核新會員 | Owner | 管理後台 → 會員管理 |
| 每週 | 處理失效連結 | 連結稽核員 → Owner 批准 | 管理後台 → 連結確認 |
| 每週 | 健康檢查與備份確認 | 除錯工程師 | `npm run doctor` |
| 每月 1、11、21 日後 | 確認實價登錄已匯入新資料 | 排程自動；異常時交除錯工程師 | 管理後台 → 排程與資料 |
| 每月 | 房市月報草稿 | 市場分析師 → Owner 批准 | `docs/02-research/market-reports/` |
| 每月 | 文件總目錄整理 | 檔案管理員 | `docs/00-INDEX.md` |
| 每季 | 回補新季別、確認規費與法規是否變動 | 資料研究員 | `TRANSCRIPTS.md`、catalog |
